🔍 Audit Perhitungan EFOR

EFOR = (FOH + EFDH) ÷ (SH + FOH) × 100%. Nilai EFDH adalah equivalent forced derating hours, bukan seluruh derating. Pemeriksaan dilakukan per unit dan untuk Sentral.

🧮 Input Operasi & Perhitungan Bulanan

PH = jam kalender setiap bulan. Konsistensi jam: SH + FOH + POH + MOH + RSH = PH. RSH berarti unit siap tetapi tidak dibebani. Derating ekuivalen harus dihitung berdasarkan penurunan MW dan durasinya.

🏭 Dashboard Sentral PLTU — Gabungan Unit 1 + Unit 2

Sentral merupakan agregasi kedua unit, tanpa input jam tersendiri. EAF dan SOF berbobot jam periode; CF berbobot MW × jam; EFOR dihitung dari jumlah FOH, EFDH dan SH. Tidak menggunakan rata-rata persentase.

📚 Referensi Rumus

AH = PH − FOH − POH − MOH
EAF = (AH − EFDH − EPDH − EMDH) / PH × 100%
EFOR (dengan validasi) = (FOH + EFDH) / (SH + FOH) × 100%
FOR = FOH / (SH + FOH) × 100%
SOF (asumsi) = (POH + MOH) / PH × 100%
SF = SH / PH × 100%
AF = AH / PH × 100%
CF = MWh bruto / (MW acuan × PH) × 100%
MTBF = SH / jumlah kejadian forced outage
MTTR = FOH / jumlah kejadian forced outage
EFDH = Σ (jam derating × MW penurunan / MW acuan)

📋 Rekap Tahunan

EFORd memerlukan data demand/reserve shutdown demand dan perlakuan derating sesuai standar. Tidak dihitung otomatis tanpa data tersebut agar tidak menghasilkan angka menyesatkan. Formula SOF dan kode SOH harus disesuaikan dengan pedoman DKKP perusahaan.

Aplikasi ini adalah alat bantu perencanaan dan analisis, bukan pengganti validasi pelaporan resmi. Indikator tahunan dihitung dari jumlah jam/energi, bukan rata-rata persentase bulanan.
